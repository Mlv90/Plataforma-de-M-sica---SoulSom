Plataforma de Música - SoulSom

Projeto front-end inspirado no Spotify, desenvolvido com HTML5, CSS3 e JavaScript.
A interface apresenta um layout moderno, responsivo e intuitivo, com seções de artistas e álbuns populares,
campo de pesquisa e área de biblioteca musical. O objetivo foi praticar a criação de interfaces,
organização de elementos visuais e desenvolvimento de uma experiência agradável para o usuário.
